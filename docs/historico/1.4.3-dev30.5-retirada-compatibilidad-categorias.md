# Core 1.4.3-dev30.5.1 — referencia técnica de compatibilidad retirada

Origen: árbol Core anterior al commit de DEV30.5 (`3a0f187`).

Se extrajeron del árbol publicable los adaptadores de categorías para Extended
Categories, Organized Categories: Core y Better Sorting. No se copia Lua ni se
mantiene código ejecutable de esos adaptadores en este documento.

La referencia conserva únicamente el alcance histórico: reescritura de
`DisplayCategory`, detección de proveedores y migración específica de reglas.
DEV30.5 los reemplaza por una resolución única: ruta nativa cuando el
clasificador produce una ruta útil; en otro caso, `DisplayCategory` vanilla; y
por último `Misc`.

DEV30.5.1 corrige su contrato: el proceso autoritativo proyecta por fila
`nativePath`, `nativeStatus`, `vanillaKey`, `effective` y `routingIdentity`.
En MP, una fila completa y coherente es la fuente de UI, búsqueda, filtros,
ordenación, tarjetas y color; el cliente no la reclasifica. La resolución local
solo cubre una instancia local o una fila sin contrato válido.

Las reglas nuevas llevan procedencia explícita: `NATIVE` para una ruta propia y
`SOURCE_CATEGORY` para una categoría segura declarada por el objeto. Las reglas
históricas sin procedencia permanecen cerradas como `DEPRECATED_EXTERNAL`, salvo
un mapa mínimo de alias GS demostrados que añade `nativePath` sin borrar
`legacyValue`. Un alias no reconocido continúa inactivo.

## Inventario técnico

| Estado | Ficheros | Motivo |
|---|---|---|
| **RETIRADO** | `GS_CategoryRewrite.lua`, `GS_ExternalCategoryMigration.lua`, `GS_ItemTaxonomy.lua`, `GS_Subcategories.lua` | Reescritura de `DisplayCategory`, detección de proveedores y taxonomía heredada. No quedan en `<ModID>/`. |
| **REEMPLAZADO** | `GS_CategoryResolution.lua`, `GS_Index.lua`, `GS_RuleSanitizer.lua`, `GS_Router.lua` | Resolución única, proyección autoritativa, procedencia persistida y lectura segura de legado. |
| **CONSERVADO** | `GS_NativeClassifier*.lua`, `GS_NativeProduct.lua`, `GS_NativeTaxonomyRegistry.lua`, `GS_CompatMods.lua` | Clasificación propia, presentación nativa y compatibilidad no relacionada con categorías. |

## Matriz estática DEV30.5.1

| Caso | Resultado exigido |
|---|---|
| Fila MP válida, incluso con clasificador cliente pendiente/error | Se conserva exactamente la resolución autoritativa. |
| Fila ausente o incompleta; instancia local | Se calcula localmente sin contaminar el contrato de fila. |
| `DisplayCategory` vanilla | Se usa su traducción `IGUI_ItemCat_<clave>` si existe. |
| Categoría segura del autor | Se conserva y muestra literalmente si no existe traducción. |
| Vacía, `B`/`F`/`W`, `native:` corrupta o clave estructural | No se acepta como categoría fuente; el fallback es `Misc`. |
| Regla `NATIVE` / `SOURCE_CATEGORY` | Sigue participando en routing. |
| Alias GS conocido | Añade `nativePath` y conserva `legacyValue`; participa mediante la ruta propia. |
| Alias GS desconocido, `FoodSpice` histórico o residuo técnico | Sigue visible, inactivo y sin conversión automática. |

Cualquier futura compatibilidad se diseñará y validará en una ronda separada,
con adaptadores explícitos y sin restaurar esta deuda técnica.
