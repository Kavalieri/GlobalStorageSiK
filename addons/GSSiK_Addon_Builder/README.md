# GSSiK Addon — Builder 1.5.0

Adds network-backed building sessions to Global Storage SiK. Materials are
claimed as exact physical instances, moved to the player inventory for the
vanilla build action and returned through the Core API when eligible.

Mod ID: `GSSiK_Addon_Builder`. Workshop: [3752437465](https://steamcommunity.com/sharedfiles/filedetails/?id=3752437465).
Requires Project Zomboid 42.20+, `SiKUIFramework` and `GlobalStorageSiK`.
The public contract lives only in [Core Integration](../../docs/INTEGRATION.md).

## Español

Añade sesiones de construcción con inventario de red. Reclama instancias

devuelve lo elegible mediante la API Core.
