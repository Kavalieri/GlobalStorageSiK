# GSSiK Addon — Craft 1.5.0

Adds network-backed crafting sessions to Global Storage SiK. It moves exact
claimed tools and materials to the player inventory, waits for authoritative
results and returns eligible items through the Core transfer API. Vanilla and
Neat Crafting are supported; Project Cook is optional and must be confirmed in
the installed runtime.

Mod ID: `GSSiK_Addon_Craft`. Workshop: [3752379654](https://steamcommunity.com/sharedfiles/filedetails/?id=3752379654).
Requires Project Zomboid 42.20+, `SiKUIFramework` and `GlobalStorageSiK`.
The public contract lives only in [Core Integration](../../docs/INTEGRATION.md).
